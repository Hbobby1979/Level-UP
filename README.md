VillageUp Open Day Registration Website

Overview

The VillageUp Open Day Registration Website is an interactive web-based platform that facilitates registration for VillageUp Open Day events. Attendees can complete a detailed registration form, cognitive assessments, and a traits questionnaire, generating personalized results and a basic CV.

Features

User Registration Form

Collects essential information such as:

Title, Full Name, Gender, Date of Birth, Nationality

Contact details (Email, Phone)

Education Level and Work Experience

Good Work Foundation (GWF) courses completed

Cognitive Questionnaire

10 multiple-choice questions testing logical reasoning and problem-solving skills.

Traits Questionnaire

30 questions assessing personality traits and suitability for roles like sales, customer service, or compliance.

Result Generation

Outputs cognitive assessment results.

Suggests the most likely discipline based on traits.

Generates a personalized basic CV.

Technologies Used

HTML5: Markup language for structuring the website.

CSS: Styling for layout and design.

JavaScript: Handles form validation, result processing, and user interaction.

How to Use

Clone or download the project files.

Open the index.html file in a web browser.

Complete the registration form, ensuring all required fields are filled.

Submit the form to:

View cognitive and traits assessment results.

Generate and view a basic CV.

Features in Detail

Registration Form

Fields:

Title, Full Name, Gender, Date of Birth, Nationality, Email, Phone, Education Level, Work Experience

GWF Courses (checkbox options):

Open Learning Academy

Bridging Year Academy

IT Academy

Conservation Academy

Hospitality Academy

Facilitator Academy

Cognitive Questionnaire

10 multiple-choice questions.

Questions are blank by default to avoid preselected answers.

Users must complete all questions to proceed.

Traits Questionnaire

30 questions with dropdown answers ("Yes," "No," "Sometimes").

All fields are initially blank, requiring user selection.

Result Generation

Displays:

Total correct answers in the cognitive assessment.

Most likely discipline based on traits.

A basic CV summarizing registration details.

Form Validation

Ensures all fields are completed before submission.

Alerts users if any field is left blank.
